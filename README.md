# Avengers Character Builder

A canvas game where character parts are placed with the keyboard to assemble characters. Block size can be changed with keyboard shortcuts.

**Live page:** https://saathvik-the05.github.io/project-avengers-character-builder/

**Built with:** HTML, CSS, JavaScript, Fabric.js

> Independent project, built in 2021 by extending the classwork versions ([v1](https://github.com/saathvik-the05/classwork-avengers-character-builder-v1), [v2](https://github.com/saathvik-the05/classwork-avengers-character-builder-v2)) with more characters and parts.
